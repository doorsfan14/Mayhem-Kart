# Mayhem Kart

A chaotic cross-platform kart racing game by Team Celeste.

## Features

- Fast-paced kart racing
- Multiple game modes
- Custom characters, karts, and tracks
- Local multiplayer
- Online multiplayer
- LAN cross-play
- Mod support
- Up to 4-player split-screen on Windows and macOS

## Multiplayer

- Cross-platform online multiplayer
- LAN multiplayer between supported platforms
- Community-hosted dedicated servers
- Up to 4 players locally on Windows and macOS

## Modding

Mayhem Kart is open source and built with modding in mind.

Mods can add custom characters, karts, tracks, and other content. Modded content can be used in LAN multiplayer.

## Platforms

- iOS/iPadOS 15.4+
- Android 8.0+
- Windows 10 20H2+
- macOS
- Linux
- Nintendo Switch
- PlayStation 4+
- Xbox One+
